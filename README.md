# 네트워크 프로젝트(TDD 기반 개발)

## 개요
**TCP/UDP 기반 네트워크 통신**, **객체 직렬화**, **동기화 시스템**을 포함한 **클라이언트-서버 구조**를 구현한 C++ 프로젝트입니다.  
멀티플레이어 환경에서의 데이터 통신, 객체 동기화, 직렬화를 핵심으로 하며 구현하였습니다.  
**테스트 기반 개발(TDD)** 로 안정성과 확장성이 용이합니다.

---

## 주요 기능

### 1. 네트워크 통신
- **TCP/UDP 서버 및 클라이언트 통신** 기능 구현  
- 멀티플렉싱 서버를 통한 **다중 클라이언트 지원**  
- 클라이언트 간 **실시간 채팅 기능** 개발

### 2. 테스트 환경
- Google Test의 **Mock 객체**를 이용한 클라이언트 네트워크 시뮬레이션 테스트 구현

### 3. 직렬화 시스템
- **MemoryStream**을 이용한 데이터 직렬화 구현  
- **Big-Endian ↔ Little-Endian** 변환
- **Write/Read 통합 Serialize 함수**로 사용하기 편하고, 유연한 대처
- **Reflection 기반 자동 직렬화 구조** 설계
  - GUI 편집기 및 디스크 저장 기능에 활용 가능

### 4. 객체 식별 및 동기화
- **LinkingContext** 확장판 설계  
- **ReplicationManager** 설계 및 점진적 구현  
- 클라이언트-서버 간 **객체 동기화 및 상태 관리** 지원
