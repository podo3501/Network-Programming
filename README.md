# 네트워크 프로젝트 개요

이 프로젝트는 TCP/UDP 기반의 네트워크 통신 기능과 객체 직렬화, 동기화 시스템을 포함한 클라이언트-서버 구조를 구현한 C++ 프로젝트입니다.

---

## 주요 기능

### 1. 네트워크 통신
- TCP/UDP 서버 및 클라이언트 통신 기능 구현
- 멀티플렉싱 서버를 통한 다중 클라이언트 지원
- 클라이언트 간 채팅 기능 개발

### 2. 테스트 환경
- Google Test와 GMock 기반 테스트 작성
- Mock을 이용한 클라이언트 네트워크 시뮬레이션 테스트 구현

### 3. 직렬화 시스템
- MemoryStream을 이용한 데이터 직렬화 구현
- Big-Endian ↔ Little-Endian 변환 지원
- Write/Read를 통합한 Serialize 함수로 성능 최적화
- Reflection 기반 자동 직렬화 구조 설계 (GUI 편집기, 디스크 저장용)

### 4. 객체 식별 및 동기화
- LinkingContext 확장판 설계
- ReplicationManager 설계 및 점진적 구현
- 클라이언트-서버 객체 동기화 및 상태 관리

---

이 프로젝트는 **멀티플레이어 환경에서의 데이터 통신, 객체 동기화, 직렬화**를 핵심으로 하며, 테스트 기반으로 안정성과 확장성을 동시에 확보할 수 있도록 설계되었습니다.
